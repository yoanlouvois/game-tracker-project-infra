Organisation
    terraform-persistent/  → ECR + bucket S3 (jamais détruits)
    terraform/             → tout le reste (détruit en fin de séance)

Module Network

    VPC (10.0.0.0/16, DNS activé)
    ├── Internet Gateway
    │
    ├── Subnets publics ×2 (eu-west-3a, eu-west-3b)
    │   └── route table "public" : 0.0.0.0/0 → Internet Gateway
    │   └── NAT Gateway (dans public[0], zone a) + Elastic IP
    │
    ├── Subnets private_app ×2 (a, b) — front + back
    │   └── route table "private-app"
    │       ├── 0.0.0.0/0 → NAT Gateway
    │       └── S3 (pl-...) → VPC endpoint S3 (Gateway)
    │
    └── Subnets private_data ×2 (a, b) — RDS
        └── route table "private-data" : aucune sortie (trafic VPC uniquement)

Module Security

    SG ALB   : in TCP 80 depuis CloudFront uniquement      | out : tout
    SG Front : in TCP 80 depuis SG ALB                     | out : tout
    SG Back  : in TCP 8081 depuis SG ALB                   | out : tout
    SG MySQL : in TCP 3306 depuis SG Back (utilisé par RDS) | out : tout

Module Registry (stack persistante)

    ECR "gametracker-dev-front" et "gametracker-dev-back"
    ├── tags mutables, scan à chaque push, chiffrement AES256
    └── lifecycle : non taggées supprimées après 7 j, 10 images max

Module Storage (stack persistante)

    Bucket S3 "gametracker-dev-mysql-backups" (n'est plus alimenté depuis RDS)
    ├── accès public bloqué, versioning, chiffrement SSE-S3
    └── lifecycle : expiration 30 j + 7 j, nettoyage des delete markers

Module Secrets

    SSM Parameter Store
    ├── /gametracker/dev/spring/datasource/username
    ├── /gametracker/dev/cloudinary/cloud-name
    └── /gametracker/dev/cloudinary/api-key

    Secrets Manager (suppression immédiate au destroy)
    └── gametracker/dev/backend → { SPRING_DATASOURCE_PASSWORD (RDS), CLOUDINARY_API_SECRET, JWT_SECRET }

Module IAM

    Rôle Front EC2 : Session Manager + pull ECR (repo front)
    Rôle Back EC2  : Session Manager + pull ECR (repo back)
                     + lecture SSM /gametracker/dev/* + lecture secret backend

Module Database (RDS)

    Subnet group : les 2 subnets private_data
    Instance RDS "gametracker-dev-db"
    ├── MySQL 8.4, db.t4g.micro, 20 Go gp3 chiffré, une seule zone
    ├── non accessible publiquement, SG MySQL
    ├── base db_pgt
    └── destroy → snapshot final ; apply suivant → restauration du dernier snapshot

Module Load Balancing

    ALB public (2 subnets publics), listener HTTP :80
    ├── /gametracker/* → TG back (:8081, health check /gametracker/v1/game/all)
    └── reste          → TG front (:80, health check /)

Module Compute

    ASG Front (min 2 / desired 2 / max 2, zones a+b)
    └── user data : login ECR → pull front:latest → run :80

    ASG Back (min 2 / desired 2 / max 4, zones a+b)
    └── user data : login ECR → lecture secret + SSM → pull back:latest → run :8081
                    → JDBC vers l'endpoint RDS (SSL), mot de passe lu dans Secrets Manager

Module CDN

    CloudFront (xxxx.cloudfront.net, HTTPS gratuit, redirection HTTP → HTTPS)
    ├── origine : ALB en HTTP
    ├── par défaut (front)  : mis en cache (CachingOptimized)
    └── /gametracker/* (API) : jamais en cache, en-têtes/JWT/body transmis
